# MarketLink Testing

## Overview

This folder contains the testing documentation and test results for the MarketLink web application.

Testing is performed to verify that the system functions according to the Software Requirements Specification (SRS), that the main user workflows operate correctly, and that invalid or unauthorized actions are handled appropriately.

The testing process covers the three main user roles:

- Customer
- Farmer
- Administrator

It also covers authentication, products, markets, orders, favorites, weekly stock, notifications, reviews, and other system functionality.

---

## Testing Objectives

The main objectives of testing are to:

- Verify that the implemented features meet the system requirements.
- Confirm that users can complete the main workflows successfully.
- Identify functional errors and unexpected behavior.
- Verify that invalid input is handled correctly.
- Verify that role-based access restrictions work correctly.
- Verify that users cannot access unauthorized information or actions.
- Verify that database-related operations work correctly.
- Check that the application remains usable across the main pages and workflows.
- Record discovered issues and track their resolution.
